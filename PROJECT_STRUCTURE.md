# Project Structure

This project is organized for clarity and ease of contribution. Here’s a quick overview:

- **README.md**: Project overview, setup instructions, and features.
- **LICENSE**: Open source license (MIT).
- **.gitignore**: Files and folders excluded from version control.
- **src/**: Main application source code.
  - **components/**: Reusable UI components.
  - **views/**: Main app pages (Check-in, Dashboard, etc).
  - **utils/**: Utility/helper functions.
  - **constants/**: Static data and translations.
  - **scoring/**: Scoring logic and workflows.
- **public/**: Static assets (images, manifest, service worker).
- **scripts/**: Node.js scripts for data management and auditing.
- **index.html**: Main HTML entry point.
- **package.json**: Project dependencies and scripts.
- **tailwind.config.js**: Tailwind CSS configuration.
- **vite.config.js**: Vite build configuration.

---

For any questions, check the README or open an issue on GitHub.
