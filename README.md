# rain

A modern web application for managing and auditing events, built with React, Vite, and Firebase.

## Project Structure

- **src/**: Main source code
  - **components/**: Reusable UI components
  - **views/**: Main app views/pages
  - **utils/**: Utility functions
  - **constants/**: Static data and translations
  - **scoring/**: Scoring logic and workflows
- **public/**: Static assets (images, manifest, service worker)
- **scripts/**: Node.js scripts for data management and auditing
- **index.html**: Main HTML entry point
- **package.json**: Project dependencies and scripts
- **tailwind.config.js**: Tailwind CSS configuration
- **vite.config.js**: Vite build configuration

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Run the development server:**
   ```bash
   npm run dev
   ```
3. **Build for production:**
   ```bash
   npm run build
   ```

## Features
- Event check-in and operations system
- Scoring and auditing tools
- Real-time updates with Firebase
- Responsive UI with Tailwind CSS
